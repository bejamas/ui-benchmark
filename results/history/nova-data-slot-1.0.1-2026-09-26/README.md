# Nova baseline before the expanded demos

These reports describe the September 26 page with data-slot 1.0.1, before the
cookie dialog, switches, notifications popover, and quick-settings menu were
added. They are historical measurements and must not be used for the expanded
September 27 page.

The reports preserve route assets, accessibility checks, visual geometry, and
five-run Lighthouse results. `baseline-readme.md` preserves the original tables;
its relative links refer to their locations in the repository root at that time.
